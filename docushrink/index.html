help

Panduan DocuShrink

1. Cara Kompres PDF

Tarik berkas PDF atau klik kotak dropzone pada tab Kompres, pilih level kompresi (Rekomendasi sangat cocok untuk dokumen umum), lalu klik 'Mulai Kompresi'.

2. Apakah Dokumen Saya Aman?

Ya, 100% aman! Seluruh pembacaan, penataan ulang, dan kompresi file dieksekusi oleh mesin JavaScript di komputer Anda. Tidak ada satu pun byte yang dikirim ke server luar.

3. Menggunakan Alat Lain

Pilih tab 'Alat PDF' untuk menggabungkan beberapa file, memisahkan rentang halaman, mengubah PDF menjadi gambar, atau mengunci PDF dengan sandi.
